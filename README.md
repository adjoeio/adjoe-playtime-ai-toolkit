# adjoe Playtime Agent Plugin Marketplace

Integrate and migrate the adjoe Playtime SDK from your AI coding assistant.

## Claude Code

Add the marketplace and install the Playtime plugin:

```text
/plugin marketplace add adjoeio/adjoe-playtime-ai-toolkit
/plugin install playtime-sdk@adjoe-playtime
```
