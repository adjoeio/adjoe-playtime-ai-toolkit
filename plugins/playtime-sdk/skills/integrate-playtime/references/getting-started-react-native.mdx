This guide walks you through adding the Playtime SDK v5 to a React Native app. The
React Native package is a native module that wraps the Android and iOS Playtime SDKs.

:::info[Shared Setup]
This setup is required for both [Catalog Integration](./standard-integration/overview.md)
and [Studio Integration](./studio/overview.md). Complete it once, then continue with
your chosen integration.
:::

:::warning[Expo Go is not supported]
`react-native-adjoe-sdk` contains native Android and iOS code and cannot run in Expo
Go. For an Expo project, generate the native projects with `npx expo prebuild` and use
a [development build](https://docs.expo.dev/develop/development-builds/introduction/)
or a production build.
:::

<Stepper>
<Step>

## Check Requirements

- React Native wrapper version 5.0.0-beta.4
- React Native 0.76 or later with Android and iOS native projects
- Node.js and the React Native toolchain configured for both platforms
- Android API 21+ and targetSdk 35
- iOS 14.0+, Xcode 26.5+, and CocoaPods
- A physical iOS device for App Attest verification
- Separate Android and iOS SDK hashes from your adjoe Account Manager

</Step>
<Step>

## Install the React Native Package

Add the v5 React Native bridge to your project's `package.json`:

```json
{
  "dependencies": {
    "react-native-adjoe-sdk": "https://github.com/adjoeio/adjoe-react-native-sdk#5.0.0-beta.4"
  }
}
```

Alternatively, install it with your package manager:

```bash
npm install --save https://github.com/adjoeio/adjoe-react-native-sdk#5.0.0-beta.4
yarn add https://github.com/adjoeio/adjoe-react-native-sdk#5.0.0-beta.4
```

The v5 package requires React Native 0.76 or later and uses React Native autolinking.
Do not manually link the package unless your project configuration requires it.

For Expo projects, generate or update the native projects after installing the
package:

```bash
npx expo prebuild
```

</Step>
<Step>

## Configure Android

Add adjoe's Maven repository to `android/settings.gradle` or
`android/settings.gradle.kts`:

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        maven { url = uri("https://releases.adjoe.io/maven") }
    }
}
```

Add the native Android SDK to `android/app/build.gradle` or
`android/app/build.gradle.kts`:

```kotlin
dependencies {
    implementation("io.adjoe:adjoe-sdk-android:5.0.0-beta.4")
}
```

Add your Android package name and Play Store ID to the adjoe dashboard, then rebuild
the native app.

</Step>
<Step>

## Configure iOS

Add the adjoe spec source and native iOS SDK to your `Podfile`:

```ruby
source 'https://github.com/adjoeio/PlaytimeSpecExternal.git'

platform :ios, '14.0'

target 'MyApp' do
  use_frameworks!
  pod 'PlaytimeSDK', '5.0.0-beta.4'
end
```

From the project root, install the pods:

```bash
npx pod-install
```

Alternatively, run `pod install --repo-update` from the `ios` directory. Open the
generated `.xcworkspace`, not the `.xcodeproj`, when building in Xcode.

Complete [App Attest setup](./getting-started-ios.mdx#configure-app-attest) and
[configure the production environment](./getting-started-ios.mdx#configure-production-environment)
for the iOS app target. These steps are required even when the app builds normally.

:::warning[Production entitlement required]
The adjoe backend does not support development App Attest attestations. Development,
TestFlight, and App Store builds must all use the `production` environment.
:::

</Step>
<Step>

## Build the Native App

Installing JavaScript dependencies is not enough after adding or upgrading a native
module. Build and launch a new native binary:

```bash
npx react-native run-android
npx react-native run-ios
```

If you use Expo, launch the development build instead of Expo Go:

```bash
npx expo run:android
npx expo run:ios
```

Verify the native setup before continuing:

1. Confirm that `react-native-adjoe-sdk` resolves from JavaScript or TypeScript.
2. Confirm that Android uses API 21 or later, targets API 35, and resolves
   `io.adjoe:adjoe-sdk-android:5.0.0-beta.4`.
3. Confirm that iOS resolves `PlaytimeSDK` 5.0.0-beta.4 and opens from the generated
   `.xcworkspace`.
4. Confirm that the Android build uses only the Android SDK hash and the iOS build uses
   only the iOS SDK hash.
5. Run the iOS app on a physical device and confirm that App Attest authenticates with
   the `production` entitlement.

</Step>
